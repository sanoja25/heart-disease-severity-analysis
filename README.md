# Heart Disease Severity Analysis

An applied statistical analysis of the Cleveland heart disease dataset using R. The project combines exploratory data analysis, regression modelling, model comparison, and diagnostic evaluation.

## Project Objective

The objective of this project is to examine the relationship between demographic, clinical, and exercise-related characteristics and the recorded heart disease severity outcome.

The analysis compares an ordinary least squares (OLS) baseline model with an ordered logistic regression model, which is more suitable for an outcome recorded in ordered severity categories.

## Dataset

The analysis uses the Cleveland heart disease dataset.

- Observations in the original file: 303
- Variables: 14
- Format: Comma-separated values
- Missing values: Represented by `?` and handled during data cleaning
- Main outcome variable: `target`

## Main Variables

The analysis includes the following variables:

- `age`: Age of the individual
- `sex`: Sex
- `cp`: Chest pain type
- `trestbps`: Resting blood pressure
- `chol`: Serum cholesterol
- `fbs`: Fasting blood sugar
- `restecg`: Resting electrocardiographic results
- `thalach`: Maximum heart rate achieved
- `exang`: Exercise-induced angina
- `oldpeak`: ST depression induced by exercise
- `slope`: Slope of the peak exercise ST segment
- `ca`: Number of major vessels
- `thal`: Thalassemia
- `target`: Recorded heart disease severity category

## Methods

The project follows these stages:

1. Data cleaning and preparation
2. Descriptive statistics
3. Target-variable distribution analysis
4. Correlation analysis
5. Box plot and scatter plot visualisation
6. OLS regression as a baseline model
7. Ordered logistic regression
8. Variance inflation factor diagnostics
9. OLS diagnostic plots
10. Model comparison using Akaike Information Criterion (AIC)
11. Predicted probability analysis

## Model Comparison

The models were compared using AIC.

| Model | AIC |
|---|---:|
| OLS baseline | 863.30 |
| Ordered logistic regression | 671.69 |

The ordered logistic regression model produced a substantially lower AIC than the OLS baseline. This indicates a better balance between model fit and model complexity for the ordered outcome.

Therefore, the ordered logistic model is treated as the preferred model, while the OLS model is retained as a baseline comparison.

## Key Findings

The ordered logistic regression results suggest that:

- Maximum heart rate (`thalach`) has a statistically significant negative association with higher recorded severity categories.
- ST depression (`oldpeak`) has a statistically significant positive association with higher recorded severity categories.
- Age, resting blood pressure, and cholesterol do not show statistically significant associations in this model.
- The results describe statistical associations and should not be interpreted as causal effects.

The estimated coefficient for maximum heart rate was approximately `-0.0285`, while the estimated coefficient for ST depression was approximately `0.6714`.
